# Company profile and progressive confirmation

Use this reference during Stage 1 only.

## Minimum opening question

Ask:

> What is the company website you want to benchmark?

If the URL points to a parent, holding company, marketplace, regional site, or similarly named entity, ask the smallest follow-up needed to identify the intended business.

## Research sequence

Start with the official website, then use reliable current sources to resolve gaps. Useful pages include About, Products, Solutions, Customers, Locations, Contact, Legal, Investor Relations, app-store publisher pages, and official social profiles.

Capture:

| Field | Guidance |
| --- | --- |
| Primary company name | Public trading or operating name |
| Official website | Canonical domain and relevant regional domains |
| Parent or owner | Include only when supported |
| Brands and products | Include only those likely to have distinct feedback profiles |
| Aliases | Former names, abbreviations, spellings, and app publisher names useful for search |
| Business model | B2B, B2C, B2B2C, marketplace, nonprofit, government, or mixed |
| Buyers | People or organizations that purchase or contract |
| Users/customers | People who use or receive the service; distinguish from buyers |
| Delivery model | Physical location, field service, web, mobile app, marketplace, or hybrid |
| Location model | None, headquarters only, single site, multi-location, franchise, service area, or customer locations |
| Countries and markets | Where the relevant offering is sold or delivered, not merely where offices exist |
| Languages | Only when material to source discovery |
| In-scope offering | Initial recommendation based on the request |
| Identity confidence | High, Medium, or Low, with the reason |
| Profile completeness | Complete, Needs confirmation, or Incomplete; list missing material fields |

Do not mistake office locations for customer markets. Do not assume a global website means global service.

## Confirmation card

Present a compact draft before continuing:

```markdown
### Draft company profile

- Company: [name]
- Website: [domain]
- Parent/brands: [list]
- Products or services: [list]
- Customer model: [B2B/B2C/etc.]
- Buyers and users: [brief distinction]
- Delivery: [physical/web/mobile/hybrid]
- Markets: [countries/regions]
- Locations: [model and known scope]
- Identity confidence: [level and why]
- Profile completeness: [status and any material gaps]

Is this the right company, and is anything material missing or incorrect before I map where its customers are speaking?
```

When evidence conflicts, show the conflict instead of silently choosing one version. Continue only after the user confirms or corrects the material scope.
